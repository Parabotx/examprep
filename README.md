# ExamPrep

A focused study space for the five-course exam week. Built with React, TypeScript, and Vite.

## Getting started

```bash
npm install
npm run dev
```

## Exam schedule

All exams are scheduled for 8:00 AM East Africa Time (Africa/Addis_Ababa). The schedule is maintained in `src/data/courses.ts`; study materials are maintained separately in `src/data/studyContent.ts` so notes, summaries, and quizzes can be added course by course.
